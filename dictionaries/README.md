# dictionaries/

Списки слів, які інструменти беруть як підказку: прізвища, пізніше імена, назви населених пунктів. Файл — звичайний текст UTF-8, один запис на рядок; необов'язкова друга колонка після табуляції — скільки разів запис трапляється (найчастіші зверху). Порожні рядки й рядки з `#` пропускаються.

| Файл | Що | Звідки |
|---|---|---|
| `surnames-khvorostiv.txt` | прізвища Хворостівської парафії з кількістю | таблиця «Хворостів, Індекси»: землевласники Руди 1931, сповідні відомості 1912, люстрації 1874, хрещення 1939; без імен |

Словник — підказка, а не правило: інструмент не підміняє прочитане слово словниковим. Як його використовує розпізнавання сканів — `import/docs/scan-recognition.md`.

Словники містять лише слова (прізвища чи назви), без імен людей поруч із ними (`AGENTS.md`, правило про персональні дані). Новий файл називаємо `<що>-<де чи звідки>.txt`.
