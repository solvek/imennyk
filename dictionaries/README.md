# import/dictionaries/

Списки слів, які інструменти й агенти беруть як підказку під час розпізнавання сканів і внесення записів: прізвища, імена, по батькові, назви місць, скорочення. Файл — звичайний текст UTF-8, один запис на рядок. Порожні рядки й рядки з `#` пропускаються.

Два види файлів:
- `.txt` — лише слово; необов'язкова друга колонка після табуляції — скільки разів воно трапляється (найчастіші зверху);
- `.tsv` — колонки через табуляцію: написання, як у джерелах, і його канон та інші поля, описані в шапці файла.

Написання в `.tsv` — сучасними літерами: дореформені `ѣ ѳ і ѵ` замінено (`ѣ→е`, `ѳ→ф`, `і/ѵ→и`), кінцевий `ъ` прибрано. Так само зводять прочитане слово перед пошуком у словнику.

| Файл | Що | Звідки |
|---|---|---|
| `surnames-khvorostiv.txt` | прізвища Хворостівської парафії з кількістю | таблиця «Хворостів, Індекси»: землевласники Руди 1931, сповідні відомості 1912, люстрації 1874, хрещення 1939; без імен |
| `surname-forms-khvorostiv.tsv` | написання прізвищ Хворостівської парафії → канон (українська, чоловічий рід) | метрика 1885 (ЛКМ КДФ 3059) |
| `patronymics.tsv` | по батькові (присвійна форма «Матѳеевъ») → ім'я батька | метрики |
| `places-khvorostiv.tsv` | назви місць парафії, як у джерелах (з відмінками) → канон і id місця в криниці | метрика 1885, довідник місць криниці |
| `words-registers.tsv` | скорочення й формули метричних книг → повна форма → колонка таблиці записів | метрики |

Словник — підказка, а не правило: інструмент не підміняє прочитане слово словниковим. Слово, якого в словнику немає, — привід перевірити прочитання, а не помилка. Як словники використовують: витягування записів зі сканів — `docs/genealogy/indexing/scan-extraction.md`. Кожна оброблена справа доповнює словники новими словами.

Словники містять лише слова (прізвища, імена чи назви), без людей поруч із ними (`AGENTS.md`, правило про персональні дані). Новий файл називаємо `<що>-<де чи звідки>.txt|tsv`; загальні, не прив'язані до місця, — без суфікса.

Імена окремого файла не мають: канон і стать лежать у словнику `name` бази. Підказку з нього дає `pnpm names:hints` (колонки: написання, канон, стать); `--out /var/tmp/given-names.tsv` пише у файл.
