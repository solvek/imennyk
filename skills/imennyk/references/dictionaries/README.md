# Довідка для читання

Загальні списки, які агент може переглянути, коли читає скан. Інструменти їх не читають: словник кожної справи живе в її банці (`hints`, `dictionary` читання).

| Файл | Що |
|---|---|
| [words-registers.tsv](words-registers.tsv) | скорочення й формули метричних книг (російська мова, XIX — поч. XX ст.) → повна форма → значення |
| [patronymics.tsv](patronymics.tsv) | по батькові в присвійній формі («Матѳеевъ») → ім'я батька |

Файл — текст UTF-8, колонки через табуляцію, рядки з `#` — шапка. Лише слова, без людей.
