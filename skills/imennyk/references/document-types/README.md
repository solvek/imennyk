# Типи документів

Кожен тип архівного документа, який індексує Іменник, має тут свій файл: як виглядає сторінка, що в ній читати, що з цього стає в банці (подія, особи, зв'язки, атрибути) і які пастки відомі. Агент, що береться за справу нового для нього типу, читає файл типу **перед** [workflow.md](../workflow.md) (там загальний порядок роботи й команди, однаковий для всіх типів).

| Тип | Файл | Подія в банці | Люди в записі |
|---|---|---|---|
| Сповідні розписи / відомості (Російська імперія, православні) | [confession.md](confession.md) | `confession` — один двір | голова двору й усі члени двору, зі зв'язками |
| Метричні книги (народження, шлюби, смерті) | [metric-books.md](metric-books.md) | `birth`, `marriage`, `death` | дитина, батьки, хресні, священник, свідки… |

Новий тип: файл за тим самим планом — зовнішній вигляд, колонки, подія й ролі, зв'язки, правила читання, пастки, приклади справ — і рядок у цій таблиці.
