# Перегляд банки в Гортачі
Гортач — локальний веб-додаток для перегляду результату читання: сумніви агента, вибірка, відсоток помилок. Запускається після `run-report`; скани мають лежати в `raw/` теки справи:

```bash
node <скіл>/scripts/gortach.mjs --root <корінь тек справ>
```

Параметри: `--root` (корінь тек справ, типово поточна тека), `--port` (типово `8090`), `--ssh` (`користувач@хост` для тунелю, типово цієї машини). Слухає лише `127.0.0.1` і входу не має. Під час запуску друкує адресу й готову команду тунелю для іншої машини (`ssh -N -L 8090:127.0.0.1:8090 користувач@хост`); після тунелю відкрийте `http://127.0.0.1:8090/` і виберіть теку справи. Запуск застосовує до `case.sqlite` нові міграції схеми. Гортач не запускають одночасно з агентом, який пише в ту саму базу.

Кнопка «Витерти скани» біля назви справи видаляє всі файли з `raw/` цієї справи (після підтвердження): її натискають, коли переглянуто всі прогони, чиї скани там лежать.

Коли в базі кілька прогонів, над закладками є вибір прогону (за замовчуванням останній); усе нижче стосується вибраного прогону.

Справа має дві закладки, кожна зі своїм прогресом «переглянуті / усі»:
- **Сумніви** — сумніви агента, лише про слова (ім'я, по батькові, прізвище, місце); фільтр за типом слова й станом.
- **Вибірка** — 20 місць із прізвищем вибраного прогону, за якими міряють помилки читання.

Запис в обох закладках однаковий: в'юпорт на скан із рамкою на потрібному місці (тягніть, щоб посунути; «−», «◎», «+» і Ctrl + колесо — масштаб), «відкрити скан повністю», прочитане агентом, варіанти й примітка агента, посилання «скан N ↗» на оригінал, стан і примітка рецензента. Зелений рядок — «правильно», червоний — помилковий, без кольору — відкритий. Дії:
- **правильно** — значення лишається;
- **не читається** — значення лишається, запис закривається з приміткою;
- **виправити** — для імені, по батькові, прізвища й місць вибірки: нове значення записується в особу й у згадки цієї частини імені того ж прогону; у вибірці правка сама робить місце помилковим; назва місця так не виправляється;
- **відкрити знову** — знімає стан і примітку, виправлене значення лишається.

Кнопка **Записати** на закладці «Вибірка» робить усі ще відкриті місця прогону «правильно», рахує відсоток помилок (виправлені + нечитабельні, поділені на всю вибірку, без нормалізації правопису) і пише його в рядок прогону (`wer`, `sample_errors`, `sample_size`). Після нових правок кнопку можна натиснути знову. Після перегляду базу комітять ще раз (у приватний репозиторій справ, якщо він є).
