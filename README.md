# Іменник

Інструмент для індексації людей в архівних документах: на вході скани справи, на виході **банка** — локальна база SQLite з особами, подіями, зв'язками, місцями й сумнівами, готова до заливки в генеалогічну базу.

Стан: заготовка. Код переноситься з [Grapa](https://github.com/solvek/grapa), де він уже працює. Мета, межі й етапи — [docs/overview.md](docs/overview.md).

*Imennyk indexes people in archival documents: scans in, a bank (a local SQLite database of persons, events and ties) out. Early stage: the code is being moved from Grapa.*
